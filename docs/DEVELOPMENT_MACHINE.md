# Development machine

These specifications describe the Linux development machine used for the local Bloodborne
port and launcher work. They are not minimum game requirements or a performance benchmark.

| Component | Specification |
|---|---|
| Laptop | HP Victus 15-fb0xxx |
| Operating system | Ubuntu 22.04.5 LTS, x86-64 |
| Processor | AMD Ryzen 5 5600H with Radeon Graphics; 6 cores / 12 threads |
| Discrete graphics | NVIDIA GeForce GTX 1650 Mobile / Max-Q |
| Integrated graphics | AMD Cezanne Radeon Graphics |
| Memory visible to Linux | 14 GiB |
| Kernel | Linux 6.8.0-138-generic |

The system has both AMD integrated graphics and NVIDIA discrete graphics. Actual game performance
depends on the selected GPU, driver, resolution, and launcher settings.
